# Privacy Policy

Last updated: 2026-08-31

Export to Markdown converts the active HTTP or HTTPS webpage into Markdown when the user invokes the extension.

## Data processing

- The extension temporarily reads the active page's rendered document, URL, and title after the user clicks the extension action.
- Mozilla Readability and Turndown process that content locally inside Chrome.
- Conversion history, consisting only of page titles, URLs, and conversion timestamps, is stored in the extension's local browser storage.
- The extension does not send webpage content, browsing history, or personal information to the developer or to an extension-owned server.
- The extension does not make network requests for conversion and does not use remote code.

## Data sharing and retention

No user data is collected, sold, transferred, or shared by the developer. Locally stored history remains in the user's browser and can be removed from the extension's History view, by clearing extension storage, or by uninstalling the extension.
