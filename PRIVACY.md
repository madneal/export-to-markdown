# Privacy Policy

Last updated: 2026-08-22

Export to Markdown converts supported webpages into Markdown when the user opens the extension popup.

## Data processing

- The extension reads the URL and title of the active tab only when the user opens the popup.
- The extension fetches the active webpage to perform the conversion locally in the browser.
- Conversion history, consisting of page titles and URLs, is stored in the browser's local storage.
- The extension does not send webpage content, browsing history, or personal information to the developer or to an extension-owned server.
- The extension does not use remote code.

## Data sharing and retention

No user data is collected, sold, or shared by the developer. Locally stored history remains in the user's browser and can be removed by clearing the extension's local storage or uninstalling the extension.
